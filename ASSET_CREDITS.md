## Project rules

1. Use only files whose license is verified from the creator or the original pack.
2. Keep each asset pack's license and attribution notice with the project.
3. Do not copy proprietary sprites, names, maps, UI artwork, or sounds from Growtopia, Pixel Worlds, Heartwood Online, or other commercial games.
4. Recolor, combine, and extend approved assets to establish GOLDEN DEPTHS' own visual identity.
5. Do not mark an asset as integrated until its file is present in this repository and its in-game rendering has been tested.

This file records approved sources; it does not claim that every listed pack has already been integrated into the running game.
